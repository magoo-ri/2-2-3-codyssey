# 2-2-3-codyssey

## 9. 1차 제작 범위 및 우선순위

처음부터 모든 기능을 완벽하게 구현하기보다 핵심 경험을 먼저 완성한다.

### 필수 1차 구현

* 메인 대시보드
* 날짜별 오늘의 미션
* 미션 완료 체크 및 기록 저장
* 오늘의 컬러 팔레트
* 간단한 디자인 안목 테스트와 해설
* 나의 아카이브(저장·조회·삭제)
* 이번 주 미션 완료 현황
* PC·모바일 반응형 디자인
/
좁은 화면 
모바일 화면 
빈 입력값 



### 이후 확장 구현

* 미션 및 퀴즈 콘텐츠 추가
* 난이도별 미션
* 랜덤 미션
* 직접 컬러 팔레트 만들기
* 주간 리포트 상세화
* 기록 내보내기

**최종 제작 목표:** 사용자가 매일 웹사이트에 방문해 5분짜리 미감 미션을 수행하고, 작은 완료 경험과 취향 기록을 꾸준히 쌓아갈 수 있는 가볍고 감각적인 개인용 웹사이트를 만든다.
